
# Shop Sales Python Pipeline

This project generates synthetic daily shop sales data using Python and SQLite.

Features:
- Automated daily sales generation
- Data cleaning and validation
- Duplicate transaction detection
- Sales performance by shop
- Top 10 best-selling products
- Revenue analysis
- JSON export for interactive dashboard

Technologies:
- Python
- SQLite
- JSON
- GitHub Actions
- GitHub Pages

All sales data is synthetic and used for educational purposes.
