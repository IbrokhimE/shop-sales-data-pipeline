
# Shop Sales Interactive Dashboard

Interactive sales analytics dashboard built using
HTML, CSS and JavaScript.

Features:
- Total sales and transaction KPIs
- Sales performance by shop
- Sales performance by product
- Top 10 best-selling products
- Top 10 products by revenue
- Daily sales trends
- Interactive shop and product filters
- Detailed sales transactions

Data is generated using Python and SQLite,
then exported to JSON.

The dashboard will be hosted using GitHub Pages.

All sales figures are synthetic and for educational use.
